### Sử Dụng Adaptive Orchestration (Recommended)
```
All Tasks → adaptive-orchestration.yaml (AUTO-SELECT workflow) 🚀

           → Simple: Direct execution (no overhead)
           → Standard: ti-cli-v2.yaml (ENHANCED MAIN) 🔄
```
