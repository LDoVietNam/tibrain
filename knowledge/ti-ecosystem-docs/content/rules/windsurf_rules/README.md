## 📋 Rule Categories

- **planning** - Project planning rules
- **implementation** - Implementation standards
- **review** - Code review requirements

### Quality Rules
- **mandatory-workflow-usage** - Workflow usage requirements
- **quality-principles** - Quality principles
- **quality-gates** - Quality gate requirements

### Security Rules
- **authentication** - Authentication requirements
- **data-protection** - Data protection rules
- **access-control** - Access control guidelines

### Performance Rules
- **optimization** - Performance optimization
- **monitoring** - Monitoring requirements
- **scaling** - Scaling guidelines

## 🚀 Using Rules

```bash
# Check rule compliance
ti rule check core/implementation

# List available rules
ti rule list

# Validate against rules
ti rule validate --all
```

## 📋 Creating New Rules

1. Choose appropriate category
2. Create rule file
3. Define rule requirements
