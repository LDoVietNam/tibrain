# Sources - CLI Source Analysis

This folder contains analysis and documentation of various CLI sources for learning and reference.

## Structure

Each subfolder represents a specific CLI source:

- **[chatgpt-cli/](chatgpt-cli/)** - ChatGPT CLI analysis
- **claude-code/** - Claude Code analysis (to be added)
- **opencode/** - OpenCode analysis (to be added)
- **kilocode/** - Kilocode analysis (to be added)
- **junie/** - Junie CLI analysis (to be added)

## Purpose

Analyze different CLI implementations to:
- Understand architecture patterns
- Learn best practices
- Identify features for Ti CLI
- Study plugin systems
- Research agent frameworks

## Adding New Sources

When adding analysis for a new CLI source:

1. Create a subfolder with the CLI name (kebab-case)
2. Add analysis documentation
3. Create a README.md with:
   - CLI description
   - Repository link
   - Local source location
   - Analysis purpose
4. Update this README.md with the new source
