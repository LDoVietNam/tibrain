# Copilot Cookie Provider

**Provider**: Microsoft Copilot
**Type**: Multi-Tier (OAuth + Cookie)
**Cookie Type**: API-based
**Last Updated**: 2026-05-08

## 🎯 Overview

Copilot appears in **2 provider tiers** in Ti Router:
1. **OAuth Provider**: Microsoft Copilot OAuth (browser-based)
2. **Cookie Provider**: Copilot Web cookie (web-based)

## 🔑 Authentication Methods

### 1. OAuth Authentication

**OAuth Provider**: Microsoft Copilot
**OAuth Endpoint**: Microsoft OAuth flow
**Status**: ⚠️ Not Configured

**OAuth Config**:
```bash
COPILOT_OAUTH_CLIENT_ID=
COPILOT_OAUTH_CLIENT_SECRET=
COPILOT_OAUTH_TOKEN_FILE=Z:\06_AUTH\copilot.oauth
```

**Pros**:
- Browser-based authentication
- No API key management
- Auto token refresh

**Cons**:
- Requires OAuth setup
- More complex configuration
- Depends on OAuth flow

### 2. Cookie Authentication (Web-Based)

**Cookie Type**: API-based
**Management**: HTTP API endpoints
**Status**: ⚠️ Not Set

**API Endpoints**:
```bash
# Set Copilot cookie
POST /api/cookie-providers/set
{
  "provider": "copilot",
  "cookie": {
    "cookie_name": "cookie_value"
  },
  "expires_in": 2592000  # 30 days
}

# Get Copilot cookie status
GET /api/cookie-providers/get?provider=copilot

# Validate Copilot cookie
POST /api/cookie-providers/validate
```

**Cookie Format**: Microsoft Copilot-specific cookie string
- Contains session information
- May include multiple cookies

**Pros**:
- Uses existing browser session
- No API key needed
- Access to web-based features

**Cons**:
- Targets reverse-engineered endpoints
- May break without notice
- Not production-ready
- Security risks

## 🔧 Usage Examples

### Setting Cookie via API

```bash
curl -X POST http://localhost:1807/api/cookie-providers/set \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "copilot",
    "cookie": {
      "your-cookie-name": "your-cookie-value"
    },
    "expires_in": 2592000
  }'
```

### Checking Cookie Status

```bash
curl http://localhost:1807/api/cookie-providers/get?provider=copilot
```

### Validating All Cookies

```bash
curl -X POST http://localhost:1807/api/cookie-providers/validate
```

## ⚠️ Security Considerations

**Cookie Authentication Risks**:
- Targets reverse-engineered endpoints
- May break without notice
- Not suitable for production
- Session expiration issues
- Potential account flagging

**Best Practices**:
- Use OAuth authentication for production
- Use cookie authentication only for testing/experimentation
- Implement proper cookie refresh logic
- Monitor for endpoint changes
- Have fallback to OAuth
