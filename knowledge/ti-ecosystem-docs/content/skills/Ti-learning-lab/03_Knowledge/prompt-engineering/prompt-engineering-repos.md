**Current**: Manual context selection  
**Improvement**: Algorithm-based selection với ranking

```python
# Context selection algorithm
def select_context(sources, query):
    ranked = rank_sources(sources, query)
    selected = top_k(ranked, k=10)
    return compress_context(selected)
```

### 2. Multi-Objective Optimization (từ SAMMO)

**Current**: Single-objective (quality)  
**Improvement**: Multi-objective (quality, cost, latency)

```python
# Multi-objective optimization
def optimize_prompt(prompt, objectives):
    score = {
        'quality': measure_quality(prompt),
        'cost': estimate_cost(prompt),
        'latency': estimate_latency(prompt)
    }
    return pareto_optimize(score, objectives)
```
